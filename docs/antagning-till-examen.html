Från antagning till examen

Den som antogs till ett treårigt gymnasieprogram ett visst år gick i normalfallet ut tre år senare. Här ställs antagningen mot examen för samma program: vilka betyg hade de antagna med sig från grundskolan – och hur gick det för avgångskullen tre år senare? Välj ett program och följ kull för kull.

Kort sagt

    Punkterna är beräknade direkt ur sidans datafiler och uppdateras när datat uppdateras.

    Två mått som inte får jämföras med varandra

    Sidan lägger två helt olika mått bredvid varandra, och de har olika skalor som inte går att räkna om till varandra:

    • Meritvärdet vid antagningen är summan av betygen från grundskolan, som mest 340 poäng. Det säger vad de antagna hade med sig in.
    • Betygspoängen vid examen är genomsnittet av gymnasiebetygen, på en skala från 0 till 20. Det säger vad avgångseleverna gick ut med.

    Att ett tal är 213 och ett annat 13,4 betyder alltså ingenting i sig – talen mäter olika saker på olika skalor. Det diagrammen kan visa är hur vart och ett av måtten utvecklats över kullarna för samma program. Kullarna är inte heller exakt samma elever: några byter program eller skola, några gör uppehåll och några tillkommer. Att ett programs siffror ändras kan bero på skolan, på vilka elever som sökte, på betygssättningen i riket eller på rena tillfälligheter i en liten grupp – det går inte att avgöra härifrån.

    Vilka program kan följas – och vilka kan inte?

    Båda källorna gäller Aranäsgymnasiet och Elof Lindälvs gymnasium, men Skolverket redovisar inte program med färre än tio avgångselever. Ett program kan därför bara följas när båda källorna har siffror för samma program på samma skola.

    Om den här sidan

    Tre år är en förenkling. Jämförelsen antar att den som antogs år X gick ut år X + 3. De flesta gör det, men inte alla: en del går om ett år, byter program eller gör uppehåll. Antagningssiffran gäller dem som antogs vid slutantagningen i juni; examenssiffran gäller alla som fullföljde programmet det året, oavsett när och var de började.

    Måtten väger olika. Medelmeritvärdet är ett ovägt genomsnitt av programmets inriktningar – GR redovisar inte hur många som antogs. Betygspoängen är däremot vägd med antalet avgångselever. Hur många elever examenssiffran bygger på står i tabellen.
