Från antagning till examen

Här ställs antagningen till ett gymnasieprogram år X mot avgångseleverna på samma program år X + 3: meritvärdena från grundskolan vid antagningen, och betygspoängen och andelen med examen vid examen. Välj ett program och se kull för kull.

Kort sagt

    Punkterna är beräknade direkt ur sidans datafiler och uppdateras när datat uppdateras.

    Två mått med olika skalor

    Sidan visar två olika mått bredvid varandra, och de har olika skalor som inte går att räkna om till varandra:

    • Meritvärdet vid antagningen är summan av betygen från grundskolan, som mest 340 poäng. Programmets tal är ett ovägt genomsnitt av dess inriktningars medelmeritvärden – GR redovisar inte hur många som antogs, så inriktningarna kan inte vägas efter storlek.
    • Betygspoängen vid examen är genomsnittet av gymnasiebetygen, på en skala från 0 till 20. Det är räknat på avgångseleverna.

    Talen mäter olika saker på olika skalor och kan inte jämföras med varandra. Diagrammen visar vart och ett av måtten kull för kull inom samma program. Kullarna är inte exakt samma elever: några byter program eller skola, några gör uppehåll och några tillkommer. Datat innehåller inga uppgifter om varför ett programs siffror ändras mellan kullarna.

    Följ ett program, kull för kull

    Varje punkt är en kull: antagningsåret står först och examensåret efter pilen. Panelerna visar tre olika mått på var sin skala: meritvärde 0–340, betygspoäng 0–20 och andel med examen 0–100 procent.

    Vilka program kan följas – och vilka kan inte?

    Båda källorna gäller Aranäsgymnasiet och Elof Lindälvs gymnasium, men Skolverket redovisar inte program med färre än tio avgångselever. Ett program kan därför bara följas när båda källorna har siffror för samma program på samma skola.

    Källor

    Sidan bygger helt på de två underliggande sidornas data: meritvärdena ur Göteborgsregionens antagningsstatistik och slutbetygen ur Skolverkets statistik över avgångselever. Alla rapporter och exportfiler finns länkade där.

    Om den här sidan

    Tre år är en förenkling. Parningen ställer antagningen år X mot avgångseleverna år X + 3. Det är inte samma individer: en del går om ett år, byter program eller gör uppehåll. Antagningssiffran gäller dem som antogs vid slutantagningen i juni; examenssiffran gäller alla som fullföljde programmet det året, oavsett när och var de började.

    Måtten väger olika. Medelmeritvärdet är ett ovägt genomsnitt av programmets inriktningar – GR redovisar inte hur många som antogs. Betygspoängen är däremot vägd med antalet avgångselever. Hur många elever examenssiffran bygger på står i tabellen.
